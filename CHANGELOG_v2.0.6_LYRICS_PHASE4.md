# Version 2.0.6 — Lyrics Workspace Phase 4

## New
- Optional Smart Structure Builder with Off, Template and Smart Generate modes
- 20 genre-aware structure presets with BPM guidance and optional MetaTags
- Live Song Map with section navigation and drag-and-drop reordering
- Per-section Vocal, Instrument and Energy Planner
- Planner-to-MetaTag insertion without changing sung lyric lines
- Song Score 2.0 with Lyrics, Structure, Vocals, Dynamics, MetaTags and Genre Fit
- Smart Advisor 2.0 with contextual composition suggestions
- Persistent Phase 4 plan model prepared for a future AI Composer
- Phase 4 interface localization for all 14 selectable languages

## Compatibility
- Existing lyrics autosave, undo/redo, MetaTag Library, Doctor, search, export and scroll behavior remain available
- Section detection expanded for all Phase 4 preset section types
