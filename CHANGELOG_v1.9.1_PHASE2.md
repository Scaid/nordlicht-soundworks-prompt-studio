# Version 1.9.1 – Phase 2

- Smart BPM recommendations based on genre and subgenre
- Optional automatic BPM selection on genre changes
- Song duration selector from 2:00 to 6:00+
- Automatic duration-aware song structures
- Drag-and-drop song structure builder
- Add/remove/reorder section controls
- MetaTag consolidation: repeated Music, Style, Chorus and Ad-libs tags are merged per section
- Duplicate values inside consolidated tags are removed
- MetaTag suggestions use the same consolidated output format
