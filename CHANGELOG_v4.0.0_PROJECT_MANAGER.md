# Version 4.0.0 – Suno Project Manager

- Added a complete local project and album manager
- Manage multiple projects, albums and track lists
- Track progress, priorities, statuses and release preparation
- Capture STYLE, Lyrics, Blueprint and Exclude data from the Studio
- Restore saved track data into the Studio
- Track-level production checklist and automatic progress
- Version snapshots with restore and delete controls
- Release fields for Suno, YouTube, Spotify, descriptions and metadata
- IndexedDB asset manager for images, audio and project files
- Project dashboard with tracks, completion, assets and versions
- JSON project import and export
- Fully local and offline
