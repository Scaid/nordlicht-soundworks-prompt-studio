# Version 2.0.3 – Lyrics Workspace Polish

## Navigation
- Smart Randomizer is now the first navigation item and the default start view.
- Lyrics Workspace moved directly below Smart Randomizer.
- Offline Smart Assistant follows after the Lyrics Workspace.

## MetaTag Library
- Fixed accordion rendering so MetaTags are visibly displayed when a category is opened.
- Sections is opened by default; open/closed categories are remembered locally.
- Live search opens matching categories automatically and highlights matches.
- Added favorite stars for individual MetaTags and a “Only favorites” filter.
- Added dynamic available/used counters.
- Added a strict `[hidden]` display rule to prevent CSS from overriding collapsed state.
- Improved independent scrolling, spacing, group counters and accordion animation.

## Localization
- Connected the Lyrics Workspace to the application language switch.
- Added complete German and English workspace text, placeholders, controls and status labels.
- Added German localization for analysis summaries, common warnings, statistics and section metadata.
- Language changes refresh the Lyrics Workspace immediately without reloading.

## MetaTag Doctor
- Added separate counters for duplicates and conflicts.
- Localized health status and safe-analysis controls.

## Version
- Updated visible version information to 2.0.3.
