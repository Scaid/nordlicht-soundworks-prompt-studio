# Version 7.5.0 – First Start Experience

## First launch
- Welcome screen when Advanced Mode is opened for the first time
- Three learning choices:
  - Quick start with only essential modules
  - Interactive guided tour
  - Expert mode with all modules
- Choice can be changed later through the floating help button

## Interactive tour
- Six spotlight steps:
  - Smart Randomizer
  - Style Builder
  - Song Director
  - AI Producer
  - Knowledge Workspace
  - Studio Intelligence
- Darkened interface with highlighted target
- Progress bar, back, next and skip controls
- Completion screen

## Beginner view
- Shows only Smart Randomizer, Style Builder, Song Director and AI Producer
- Export remains available
- All hidden modules remain intact and can be restored instantly

## Context help
- Floating onboarding/help button
- Restart tour
- Switch between beginner and expert views
- Reset first-time setup
- One-time contextual tips for important modules

## Languages
- First Start Experience registry for all 14 shipped interface languages
- Language changes are applied to the onboarding without reloading
