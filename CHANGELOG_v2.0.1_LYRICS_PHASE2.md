# Version 2.0.1 – Lyrics Workspace Phase 2

## New
- Drag-and-drop MetaTag library with 100+ curated tags in ten categories.
- Context-aware Smart Suggestions based on the song section at the cursor.
- Click-to-insert and custom MetaTag input with automatic square brackets.
- Drag MetaTags directly to the desired editor position.
- Drag detected song sections in the structure panel to reorder complete blocks.
- Search and category filters for the MetaTag library.
- Responsive three-column desktop layout and compact tablet/mobile layouts.

## Compatibility
- Existing Style Builder, Randomizer, presets, Live Output and Lyrics Phase 1 tools remain intact.
- Lyrics continue to be stored locally and remain separated from Builder presets.
