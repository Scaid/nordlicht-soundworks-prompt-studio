# Version 2.0.7 – Genre & Instrument DNA

- Dedicated Swing / Vintage Jazz family with 26 subgenres, including Electro Swing.
- Broad genre expansion across electronic, folk, metal, rock, pop, hip-hop, world and soundtrack styles.
- Genre profile and BPM/instrument knowledge for Swing and Electro Swing.
- BPM output now combines a numeric value with an optional tempo character.
- Lyrics language is no longer placed in Style by default; an opt-in control remains available.
- Instrument reliability levels: Core, Advanced and Experimental.
- Reliability filter, badges and legend in the Instrument Library.
- Instrument role descriptions adapt selected instruments to the current genre.
- New Instrument DNA module prepared for the AI Composer.
